# 五部 AGE2 独立中文资源：研究工作稿

2026-09-14，范围为 Steam TDA00–03 与 The Imperial Capital Burns。

本轮是资源更新与局部运行验证，不是五部作品的发布验收。

## 资源与布局规则

- 当前四部 TDA 原包 AVIF 数为 0；帝都含 AVIF，包括需要本地化的文字背景。
- 正文及片尾只写 `zh_hans`，逐条检查其余语言槽及记录顺序不变。
- UI 使用 `_zh`，剧情图使用独立中文资源键 `_ck`；框架语言号、EGPACK 槽和图片后缀不是同一层。
- TDA 共用冷蓝样式及中文文案，帝都使用暖橙样式。共享样式不代表可跨作直接复制图像尺寸。
- UI 以本作实际日文布局为参照。TDA03 原生 `_zh` 中存在带 `zh` 标记的开发占位图，不能把占位图尺寸当作最终布局依据。
- 保留原版英文标题与图标，中文副标题放回原日文副标题区域。操作说明保留原画布、外框及英文标题图，内部用代码重新排版。
- 字幕以实际 alpha 边界居中，不能仅用字体 advance width；帝都本轮 74 张字幕使用 1280×720 画布、673 像素底边。
- 日文原始字幕可能是 1×1 透明占位。这种图不能作为中文字图画布参照，应查看配对英文资源及脚本。

## 实现

- `tools/images/ui_zh.py`：共用文案和原版副标题区域渲染。
- `tools/images/manual_zh.py`：两套配色的桌面及触摸说明。
- `tools/egpack/credit_roles.tsv`：五部共用的片尾岗位译名。
- `games/imperial-capital-burns/tools/build_phase1.py`：按可见像素修正字幕居中。
- `tools/fpd/fpd_codec.py`：修正 TDA00 FPD v1 的绝对名字偏移；v2 仍按名字池相对偏移解析。

原始提取资源、历史补丁输入、完整构建脚本及可视预览保留于本地忽略目录
`local-internal/age2-cn-slot-research/refresh` 与其上一级，未纳入可发布源文件。

## 片尾范围

先从游戏脚本找到实际 staffroll ID，再从对应 localized XML 找 `$record` 引用。
帝都实际调用 224 条片尾记录，其余 725 条未调用记录保持原中文槽。

岗位、功能说明译中文；真实人员、公司、歌曲名和 logo 保留原署名。
角色名和军衔译中文，同一行演员姓名仍保留原文。空白／控制记录不补文字。
公开翻译表与历史补丁正文存在差异，本轮未将两者进行未经审定的全量覆盖。

## 验证及未完成项

328 个生成 EGPACK 表逐条保留非中文槽；33 项相关测试通过。
帝都研究版实测新 UI、中文→英文→日文→中文菜单切换及序章字幕；日志确认
独立 `_ck.webp`／`_ck.avif` 文件成功打开。测试后关闭游戏。

仍需运行验证：

- 帝都 7 个场景的 26 处字幕脚本坐标与切换后的脚本缓存。
- 片尾 XML 的 `data_en` 日文常量旁路；候选修正改成同一 `$record` 引用，尚未接入实机。
- 五部片尾实际滚动排版及所有字幕／字卡切换。
- TDA 四部独立中文槽的运行接入；当前是资源工作稿，不能当作四个可安装版本。

字体对照采用原版 NewCinemaA／Skip 与开源霞鹜漫黑／思源黑体。本轮 UI 使用思源黑体，
霞鹜漫黑仅为正文风格候选，不宣称与原字体等价，也未强制替换全篇正文。

## UI 第二版：原版副标题的视觉关系

第二版中文菜单采用 Noto Sans SC 可变字体的 450 字重。按日文不透明字芯量取字高，
避免将光晕尺寸计入字号；从每张原图取字芯与光晕颜色，分开绘制柔和宽光晕和近距离辉光。
普通标题沿原版左对齐，Main Menu 沿原版右对齐，标题菜单按钮保留居中。
普通／悬停图使用同一套字芯尺寸和锚点，光晕变化不再造成中文字跳动。
说明型副标题使用「从头开始游戏」「更改各项设置」「保存当前进度」等自然文案。

五部共 214 张中文菜单纹理重新生成，上一版在本地 `cn-ui-v1` 保留；
原生画布尺寸、上部英文主体像素逐图检查，82 张帝都 UI 更新到隔离研究版。
本次为纹理和字体的离线视觉检查，没有重新运行游戏验证。

正文增加小赖 Regular、悠哉 Regular／Medium、霞鹜文楷 Medium 对照。
这些候选及霞鹜漫黑都覆盖现有 328 张中文表的 3,556 个不同非空白字符；
这是字符映射检查，不代表已经验证全篇排版。正文与姓名字体尚未替换。
小赖较接近原版直立、等线手写结构，但偏圆厚；悠哉偏斜，文楷的楷书笔形更明显。
原版 NewCinemaA 与 Skip 是两种不同设计，不能用单一中文字体宣称完整还原。

本地构建入口为 `refine_ui_fonts.py`，核对及更新入口为 `promote_ui_v2.py`。
