# WebP 字幕错位根因与当前资源检查

本轮为源代码历史、原版脚本与本机安装资源的静态调查，没有运行游戏，也没有修改字幕脚本或 TDA 图片位置。

## 已证实的历史原因

1. 提交 `d12911e` 中 `build_phase1.py::patch_telop_positions` 将原版 `0,-2145,723`、`0,-2170,723` 改成普通字幕的 `0,-1550,723`。这些抬高坐标用于字幕与正文同时显示；旧处理错误地消除了这项演出布局，造成正文遮挡。`02a189d` 中已改为原样恢复原脚本，函数名沿用但不再归一化坐标。
2. 旧 `render_telop` 使用字体排版框居中，没有对最终 alpha 可见字形重新定位；侧边距、全角标点留白会造成实际字形偏移。现行版本重新量取 alpha 边界，在原画布内按可见像素居中，底边固定 673。
3. 旧渲染使用 32px 字号、4px 描边，没有抬高字幕高度限制。现行版本统一 24px、2px 描边，并以对应英文字幕的实际高度限制抬高字幕，避免中文额外换行超出这类演出的空间。历史记录只对 59、60、63、73 做过原坐标合成场景运行验证，不等同全部原剧情逐段验收。

这不是 WebP 压缩格式本身的问题，也不是运行时正文自动换行的问题。字幕图内部布局和脚本放置坐标共同决定最终显示。

## 当前结果

检查脚本：`local-internal/age2-cn-slot-research/audit_current_telop_layout.py`。
结果：`five-game-review/image-fixes-20260920/current-telop-layout-audit.json`。

- 帝都 74 张当前字幕全部为 1280×720，alpha 底边 673，可见像素水平居中误差不超过 0.5px，本机文件与候选一致。
- 19 张用于抬高位置的字幕，其高度均不超过对应英文参照。
- 扫描了 28 个含字幕引用的 XML（14 个 localized 加上对应非 localized 文件，包含退避脚本；不是 28 个独立剧情段落）。所有已有本机与候选 loose XML 中的字幕指令属性与原版相同，已有本机 loose 文件全文也与原版一致；没有 loose 文件的位置使用原包。
- localized 中的 7 个特殊场景、26 处抬高调用已恢复原版；非 localized 对应副本同样通过。
- 另查 13 张 TDA 附加字幕：原画布保持，本机与候选一致，没有裁切。但 TDA03 的 `TDA03C_J0001` 到 `TDA03C_J0005` 可见字形中心比英文参照偏左 5.5–6px。当前 `build_tda_missing_captions.py` 仍按 `multiline_textbbox` 布局，没有像帝都生成器那样对最终 alpha 重新对齐。这是同类测量框留白问题的轻微残留，不是脚本坐标被改或大幅错位。本轮未修改这 5 张图。

以上结论覆盖本轮检查的图片和磁盘脚本；不证明所有运行时语言切换、缓存和显示时机均已实机通过。
